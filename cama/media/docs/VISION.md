# VISION: CAMA Media Memory

## Why this exists

Thousands of photos and videos already exist: road trips, Florida adventures,
family, pets, school, AI work, Lorien's Library, wildlife, sunsets, funny
encounters, everyday life. The bottleneck is not creating content. It is that
the **meaning and relationships** inside that content are trapped in a camera
roll. A camera roll is a flat, chronological pile. It does not know that three
photos belong to the same afternoon, that a dog appears in both, that a place
was peaceful, or that a moment was never posted and still matters.

Media Memory turns that pile into **connected memory**.

## What it is

A persistent memory system that can **understand, organize, retrieve, and
connect personal media over time**. When media is imported, the system retains
and connects information such as:

- Who appears in it (via explicit user labeling; see PRIVACY_SAFETY.md)
- Where it happened
- When it happened
- What activity or event it belongs to
- The emotional tone
- Objects, animals, landmarks, and scenery
- Related photos or videos
- The larger trip or story it belongs to
- Whether it has already been posted, on which platform, with what caption and hashtags
- How the post performed
- Why the memory may matter later

The goal is not image tagging. It is **persistent, relational understanding
across a growing personal media history**.

## What it is not

- Not a generic social-media planner. The library is the product; the calendar
  is one view into it.
- Not a cloud photo service. It is local-first; originals stay on the owner's
  device.
- Not a facial-recognition system. Identity comes from explicit user labels,
  never from automatic identification of unknown people.

## Example queries it should eventually answer

- Show me every Florida sunset with Apollo.
- Find all the unused photos from our Boca Grande trip.
- Show me funny encounters involving animals.
- Find pictures from trips Ryan and Zeke were both on.
- What content have I never posted?
- Find peaceful road-trip photos for a reflective post.
- Build a carousel from our Spook Hill adventure.
- Show me memories related to graduating and starting my bachelor's degree.
- Find older photos that match what I am posting about today.
- What kinds of posts perform best with my audience?

## Why it belongs in CAMA

Media Memory is a concrete test bed for the broader CAMA thesis: persistent
memory is not only for conversations. The same primitives CAMA already provides,
provenance (teaching / exchange / inference), emotional indexing (valence,
arousal, emotion chord), associative retrieval, temporal recall, counterweights,
consent, and the right to forget, apply directly to media. A photo's derived
tags are **inferences** (provisional until confirmed). A user's correction is a
**teaching** (durable, authoritative). A moment's feeling is an **emotional
signature**. "Why this may matter later" is **significance**. Building media on
top of CAMA proves the memory model generalizes across modalities.
